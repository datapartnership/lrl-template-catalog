Metadata schemas

Every dataset in the catalog is described with structured metadata, so it is easy to find and reuse for training and fine-tuning models.

Four goals

Discoverability

Making datasets easy to find and correctly identify.

Usability

Giving clear information so users can assess and work with datasets effectively.

Reproducibility

Documenting processes so results can be verified and reused.

Ethical practice

Documenting provenance, licensing and ethical safeguards openly.

An application profile

No single existing standard met every requirement, so the metadata combines fields from several standards. It also uses a custom vocabulary for program-specific attributes, while staying compatible with existing tools.

Standards used

  • Croissant
  • Schema.org Dataset
  • Dublin Core Terms
  • DCAT
  • Data Quality Vocabulary (DQV)
  • PROV-O
  • RDF Schema
  • EBUCore
  • OLAC
  • BIBO
  • DDI
  • DDPV (custom vocabulary)

Schemas by data type

There are metadata schemas for three kinds of data: audio, text and video. Most fields are the same. The main difference is the technical fields each type needs, such as duration and sample rate for audio, and word counts for text. The full documentation lists every field, its definition, how often it must appear, and how it is collected.
